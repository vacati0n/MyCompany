# Architecture Decision Record D-004

## Metadata

- ADR ID: D-004
- Title: Registration of one stored copy per beat by the one writer, measured from that copy, with release fields recorded or absent
- Date: at emission in run-dfcae1756c32
- Status: Proposed
- Owners: architect (producer); omn-tech-lead (accepting owner of the Design Gate)
- Related Work Items: MC-11; the supplied execution plan's design tasks

## Context

- Problem statement: No recording can be registered, and nothing binds a hash to the bytes later decoded.
- Business and technical constraints: C-003, C-008, C-010.
- Current architecture baseline: F-004, F-007, F-025.

## Decision

- Selected option: O-001
- Decision statement: A pure set check matches beat-numbered files to the material's beats; each file is copied, promoted and hashed by the one writer, probed, decoded and measured from the stored copy and re-hashed; the release fields are recorded or absent; the document is hashed from outside the repository and stored nowhere; every reader re-checks the hash.
- Scope of impact: M-002, M-009, M-012, M-014.

## Alternatives Considered

1. O-004: Recordings read in place from the operator's folder
- Benefits: No copy of the recordings
- Risks: Bytes outside the writer's promote-once control between hash and decode
- Why not selected: Ties on hard constraints and impact; loses on reuse

2. O-008: Mixed-format recordings resampled to the first file's format
- Benefits: No refusal of a mixed set
- Risks: A format target the owner did not set; joined audio differs from its parts
- Why not selected: Eliminated: violates C-008

## Consequences

- Positive outcomes expected: Only the registered bytes ever narrate, under a recorded release.
- Tradeoffs accepted: Recordings are stored twice, the operator's and the company's copy.
- Risks introduced: R-006, R-016

## Validation Plan

- Metrics to monitor: Registered hash equal to every part artifact's hash of a recording-sourced production.
- Verification checkpoints: A byte changed before each reader in P-019; the absent-field registration in P-011.
- Rollback or reversal conditions: A narrated part whose hash differs from its registration.
