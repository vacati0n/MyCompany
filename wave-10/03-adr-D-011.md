# Architecture Decision Record D-011

## Metadata

- ADR ID: D-011
- Title: The commands, the settings and the orchestrator's ordered company-store steps
- Date: at emission in run-dfcae1756c32
- Status: Proposed
- Owners: architect (producer); omn-tech-lead (accepting owner of the Design Gate)
- Related Work Items: MC-11; the supplied execution plan's design tasks

## Context

- Problem statement: No command registers, verifies or produces from an own source, and the company-store run needs an order.
- Business and technical constraints: C-009, C-012, C-016.
- Current architecture baseline: F-014, F-015, F-042.

## Decision

- Selected option: O-001
- Decision statement: Registration and verify-model commands, the own produce mode, an install option naming the first resource, a model settings section with no default in code, vendor members optional, and the orchestrator's steps from backup to post-run readings with structural network evidence.
- Scope of impact: M-007, M-018, M-021.

## Alternatives Considered

1. O-005: Expected hashes written to the store by an installation command
- Benefits: Hashes travel with the store
- Risks: A store write before the go
- Why not selected: Eliminated: violates C-009

2. O-003: Vendor bar as a settings value
- Benefits: One switch for every source
- Risks: A settings edit re-admits the vendor
- Why not selected: Eliminated: violates C-002

## Consequences

- Positive outcomes expected: The owner and the orchestrator run documented commands only.
- Tradeoffs accepted: The installation record is a settings section, not a command.
- Risks introduced: R-001, R-009

## Validation Plan

- Metrics to monitor: Every documented command's exit code in the demonstration store.
- Verification checkpoints: The guide's commands run as documented in P-017.
- Rollback or reversal conditions: A documented command that needs a code change, a secret or a vendor credential.

- Tech Lead: unsigned; acceptance belongs to the Design Gate
- Product Owner (if scope-impacting): unsigned
