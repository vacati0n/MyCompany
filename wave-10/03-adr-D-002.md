## Decision

- Selected option: O-001
- Decision statement: No branch of the rule yields the vendor and the rule reads no setting; the refusal names the owner's decision; an internal entry of the produce service runs a named source below the rule for the vendor-path tests, which keep every assertion; a new test proves the rule never yields the vendor.
- Scope of impact: M-002, M-005, M-020.

## Alternatives Considered

1. O-003: Vendor bar as a settings value
- Benefits: One switch for every source
- Risks: A settings edit re-admits the vendor
- Why not selected: Eliminated: violates C-002

2. O-002: Model process started by a sibling type
- Benefits: The model's invocation sits apart from the media tool
- Risks: Duplicates the delivered bound and process-tree termination; widens the one-starter assertion
- Why not selected: Ties on hard constraints and impact; loses on reuse

3. O-004: Recordings read in place from the operator's folder
- Benefits: No copy of the recordings
- Risks: Bytes outside the writer's promote-once control between hash and decode
- Why not selected: Ties on hard constraints and impact; loses on reuse

## Consequences

- Positive outcomes expected: No settings edit can call the vendor, and the vendor path stays tested.
- Tradeoffs accepted: Plan-only previews the own mode; re-admission needs a code change and a recorded decision.
- Risks introduced: R-010, R-022
