# Architecture Decision Record D-005

## Metadata

- ADR ID: D-005
- Title: The model run by the one delivered starter: the isolated interpreter, explicit files and settings, text by file
- Date: at emission in run-dfcae1756c32
- Status: Proposed
- Owners: architect (producer); omn-tech-lead (accepting owner of the Design Gate)
- Related Work Items: MC-11; the supplied execution plan's design tasks

## Context

- Problem statement: The model must run in house with no network and nothing held, through an architecture-tested boundary.
- Business and technical constraints: C-005, C-007, C-016.
- Current architecture baseline: F-004, F-027, F-028, F-029.

## Decision

- Selected option: O-001
- Decision statement: The one starter gains the model invocation behind a new port: the environment's interpreter in isolated mode with bytecode writing off runs the runtime as a module, given full file paths and all six generation settings, text through a staged file, output promoted by the one writer; tests use a stand-in executable.
- Scope of impact: M-003, M-004, M-020.

## Alternatives Considered

1. O-002: Model process started by a sibling type
- Benefits: The model's invocation sits apart from the media tool
- Risks: Duplicates the delivered bound and process-tree termination; widens the one-starter assertion
- Why not selected: Ties on hard constraints and impact; loses on reuse

2. O-007: The runtime's console launcher with the inherited environment
- Benefits: The runtime's own entry point
- Risks: Inherited interpreter variables may redirect the code that runs
- Why not selected: Ties on hard constraints and impact; loses on reuse

## Consequences

- Positive outcomes expected: One starter, explicit inputs, no lookup that could fetch a voice.
- Tradeoffs accepted: The voice is loaded once per part.
- Risks introduced: R-001, R-013

## Validation Plan

- Metrics to monitor: Zero processes started outside the one starter; recorded argument lists naming files only.
- Verification checkpoints: The one-starter assertion and stand-in bound tests in P-010 and P-016.
- Rollback or reversal conditions: The isolated interpreter fails to start the runtime in the orchestrator's demonstration run.
