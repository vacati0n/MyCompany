# Architecture Decision Record D-012

## Metadata

- ADR ID: D-012
- Title: The dashboard is console text printing the composed read's lines as tiles, with no file, listener, action or secret
- Date: 2026-10-09
- Status: Proposed
- Owners: omn-tech-lead as the accepting owner of the Design Gate under the producer exclusion rule; architect as the producing agent
- Related Work Items: MC-9; technical design package DESIGN-2026-0009; planner tasks T-014, T-029 and T-045; sequencing constraints P-010 and P-012

## Context

- Problem statement: the owner needs a dashboard over the same read, and the repository's only surface is an operator command entry point with no web stack.
- Business and technical constraints: C-009 no listener, web stack or secret; C-003 no write path or capability reference; C-001 the same read.
- Current architecture baseline: F-002 records the entry point, its commands and the absent listener; F-025 the boundary assertions.

## Decision

- Selected option: O-002.
- Decision statement: a dashboard command composes one read and prints, to standard output, one tile per brief line, each the line's own rendering with the instant and case; it writes no file, opens no listener, offers no action and prints no connection string, handle or credential.
- Scope of impact: M-016 adds the command; M-010 composes the tiles; M-019 asserts the boundary.

## Alternatives Considered

1. O-006, a page served on a local port
- Benefits: a familiar dashboard
- Risks: a network listener and a web stack
- Why not selected: eliminated by C-009

2. O-007, a rendered file the owner opens
- Benefits: a persistent view
- Risks: the company's position kept on disk beyond the read and no reuse of the console
- Why not selected: not selected on reuse leverage and operability

3. O-001, O-003, O-004, O-005, O-008, O-009 and O-010, the other options of the package evaluation
- Benefits: each carries this decision unchanged
- Risks: each differs from O-002 in another design area only
- Why not selected: none is decided on this record

## Consequences

- Positive outcomes expected: no new exposure, and every tile equals its line.
- Tradeoffs accepted: the dashboard is text, read where the operator runs it.
- Risks introduced: R-013, a gained write path; R-014, a printed secret.

## Validation Plan

- Metrics to monitor:
  - The count of tiles differing from their line in instant or case; the expected value is zero.
  - The count of listeners, files written and actions offered; the expected value is zero.
- Verification checkpoints:
  - Every tile compared with its line over one read.
  - The boundary assertions on every solution build.
- Rollback or reversal conditions:
  - Reversed if the owner asks to read the dashboard away from the operator's machine; a threat review then precedes any other form.
