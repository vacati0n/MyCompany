# Architecture Decision Record D-014

## Metadata

- ADR ID: D-014
- Title: One writer under one output root outside the repository
- Date: at emission in run-7ae81c0de400
- Status: Proposed
- Owners: architect (producer); omn-tech-lead (accepting owner of the Design Gate)
- Related Work Items: MC-10; the supplied execution plan's design tasks

## Context

- Problem statement: Nothing writes files today and a recorded hash must name stored bytes.
- Business and technical constraints: C-007, C-016.
- Current architecture baseline: F-040.

## Decision

- Selected option: O-001
- Decision statement: ArtifactWriter writes to staging, flushes, promotes, re-reads to hash, then records; refuses a root inside the configured repository root by path containment.
- Scope of impact: M-021, M-015.

## Alternatives Considered

1. O-009: Tracked tree found by version control
- Benefits: Exact tracked-tree test
- Risks: A second process-starting site
- Why not selected: Eliminated: violates C-007

## Consequences

- Positive outcomes expected: Every recorded hash names stored bytes; an interruption leaves no record.
- Tradeoffs accepted: Staging is cleared at each run's start.
- Risks introduced: R-013

## Validation Plan

- Metrics to monitor: Hash recomputation after the run; injected interruption.
- Verification checkpoints: Writer tests in P-008.
- Rollback or reversal conditions: A recorded hash differing from its file reverses the ordering.

- Architect: unsigned; the producer does not accept its own record
- Tech Lead: unsigned; acceptance belongs to the Design Gate
- Product Owner (if scope-impacting): unsigned
