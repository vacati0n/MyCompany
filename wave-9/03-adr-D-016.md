# Architecture Decision Record D-016

## Metadata

- ADR ID: D-016
- Title: The prepare command loading recorded configuration and the package
- Date: at emission in run-7ae81c0de400
- Status: Proposed
- Owners: architect (producer); omn-tech-lead (accepting owner of the Design Gate)
- Related Work Items: MC-10; the supplied execution plan's design tasks

## Context

- Problem statement: Nothing loads the records the metered run needs or the item package.
- Business and technical constraints: C-005, C-009, C-011.
- Current architecture baseline: F-039, F-010, F-016.

## Decision

- Selected option: O-001
- Decision statement: Prepare inserts company, channel without amount, accounts with fixed identifiers, models, routes, prices, item, dossier version 1, material, cap and designation where absent and refuses a differing row.
- Scope of impact: M-015, M-018, M-025.

## Alternatives Considered

1. O-002: Production types in the host executable
- Benefits: No new assembly
- Risks: Production path testable only through the executable; host no longer composition only
- Why not selected: Ties on hard constraints, impact and reuse; loses on quality

## Consequences

- Positive outcomes expected: Variable names are fixed before the guide is written; the company store is loaded only by the orchestrator.
- Tradeoffs accepted: The recorded configuration carries prices the orchestrator re-fetches.
- Risks introduced: R-001, R-022

## Validation Plan

- Metrics to monitor: Idempotent re-runs; refusals on differing rows.
- Verification checkpoints: Demonstration-store load tests in P-011.
- Rollback or reversal conditions: A load writing a channel amount reverses the shape.
