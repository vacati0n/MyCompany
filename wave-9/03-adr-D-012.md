# Architecture Decision Record D-012

## Metadata

- ADR ID: D-012
- Title: The production path in a new assembly
- Date: at emission in run-7ae81c0de400
- Status: Proposed
- Owners: architect (producer); omn-tech-lead (accepting owner of the Design Gate)
- Related Work Items: MC-10; the supplied execution plan's design tasks

## Context

- Problem statement: The Audio handler must reach the boundary, which the rule-determined assembly may not reference, and the host is a composition root.
- Business and technical constraints: C-004, C-007, C-017.
- Current architecture baseline: F-040, F-043.

## Decision

- Selected option: O-001
- Decision statement: MediaCompany.Production holds the produce service, the four handlers, the one process starter and the one writer, referencing domain, ports, the rule-determined assembly and the boundary.
- Scope of impact: M-019, M-020, M-021, M-018.

## Alternatives Considered

1. O-002: Production types in the host executable
- Benefits: No new assembly
- Risks: Production path testable only through the executable; host no longer composition only
- Why not selected: Ties on hard constraints, impact and reuse; loses on quality

2. O-008: Handlers in the rule-determined assembly
- Benefits: Handlers beside the copyright handler
- Risks: The Audio handler cannot reach the boundary
- Why not selected: Eliminated: violates C-004

## Consequences

- Positive outcomes expected: The production path is testable as a library.
- Tradeoffs accepted: One more project in the solution.
- Risks introduced: R-016

## Validation Plan

- Metrics to monitor: Dependency assertions on the new assembly.
- Verification checkpoints: Boundary suite in P-013.
- Rollback or reversal conditions: A dependency cycle reverses the placement.
