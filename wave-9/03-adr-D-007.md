# Architecture Decision Record D-007

## Metadata

- ADR ID: D-007
- Title: Billed unit kinds priced and costed in the datastore
- Date: at emission in run-7ae81c0de400
- Status: Proposed
- Owners: architect (producer); omn-tech-lead (accepting owner of the Design Gate)
- Related Work Items: MC-10; the supplied execution plan's design tasks

## Context

- Problem statement: Only input, output and cached kinds are priced and costed, so the speech route is unselectable.
- Business and technical constraints: C-011, C-015.
- Current architecture baseline: F-019, F-020, F-021, F-022.

## Decision

- Selected option: O-001
- Decision statement: Character and image kinds; recorded billed kinds per model; a model priced when every billed kind has a price; the stored cost covers five kinds.
- Scope of impact: M-002, M-010, M-014, M-016.

## Alternatives Considered

1. O-002: Production types in the host executable
- Benefits: No new assembly
- Risks: Production path testable only through the executable; host no longer composition only
- Why not selected: Ties on hard constraints, impact and reuse; loses on quality

## Consequences

- Positive outcomes expected: The speech route becomes admissible without relaxing the refusal of an unpriced billed kind.
- Tradeoffs accepted: A schema change to the stored cost.
- Risks introduced: R-008

## Validation Plan

- Metrics to monitor: Bookings with and without a cached price.
- Verification checkpoints: Booking tests in P-004.
- Rollback or reversal conditions: Stored values changing on existing rows reverse the expression change.

- Tech Lead: unsigned; acceptance belongs to the Design Gate
