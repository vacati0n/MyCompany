# Architecture Decision Record D-001

## Metadata

- ADR ID: D-001
- Title: Graphic specifications are per-item data drawn by a closed subject-free element and motion set, checked against the recorded package with a decidable number rule
- Date: at emission in run-9d83536ecd16
- Status: Proposed
- Owners: architect (producer); omn-tech-lead (accepting owner of the Design Gate)
- Related Work Items: MC-12; the supplied execution plan's design tasks

## Context

- Problem statement: Each graphic position is a text card (F-004); nothing records what a graphic draws or traces its labels and numbers to a source.
- Business and technical constraints: C-001, C-002, C-010, C-017, C-018.
- Current architecture baseline: F-004, F-015, F-016, F-035, F-039.

## Decision

- Selected option: O-001
- Decision statement: One UTF-8 JSON specification per position in a graphics folder beside the item material, named from the material's identifier; a closed set of text, point, bearing, path, axis, trace, angle, region, panel, blocks and bars elements and reveal, rotate, sequence, grow and follow motions; every text element carries its source path and verbatim quotation; a figure is any text with a decimal digit or a listed number word, admitted only from the claim record or an owner-admitted source; every quantity layout value is schematic with the owner's wording or cites the owner answer; the check reads each specification's bytes once and names every refusal.
- Scope of impact: M-009, M-015, M-016.

## Alternatives Considered

1. O-004: Each graphic is its own drawing component
- Benefits: Fewer data files
- Risks: Subject terms and on-screen literals in code; quotations unverifiable as data
- Why not selected: Eliminated: violates C-010

2. O-002: Graphics drawn by the media tool's filter graphs
- Benefits: No Node process
- Risks: Not the owner-approved renderer; weak text shaping
- Why not selected: Eliminated: violates C-008

## Consequences

- Positive outcomes expected: Every drawn character is traceable to a quoted source and every quantity is disclosed or owner-admitted; another item needs only data.
- Tradeoffs accepted: Twenty-two data files and a check holding a closed English number-word list; Markdown emphasis characters removed for matching only.
- Risks introduced: R-013, R-021

## Validation Plan

- Metrics to monitor: Refusals per injected fault; the printed figure set against the ruled set.
- Verification checkpoints: The check's fixture tests in P-004 and the quotation evidence in P-019.
- Rollback or reversal conditions: A drawn character with no quotation, or an admitted figure outside the ruled set, reaches a frame.
