# Command: Implement Feature

## Purpose

Execute the feature delivery workflow defined in `workflows/implement-feature.md`.

## Required Inputs

- Business objective and target users.
- Functional scope and non-goals.
- Acceptance criteria.

## Assigned Agents

- Primary: `product-owner`.
- Secondary: `architect`, `dev-1-implement`, `dev-2-reviewer`, `qa`.

## Outputs

- Approved design artifact.
- Implemented and tested feature.
- PR summary and release-note entry.
