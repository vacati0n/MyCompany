# Command: Prepare Release

## Purpose

Execute release preparation and readiness checks using `workflows/release.md`.

## Required Inputs

- Release scope and target version.
- Environment target and deployment window.
- Rollback and communication requirements.

## Assigned Agents

- Primary: `tech-lead`.
- Secondary: `qa`, `documentation`, `product-owner`.

## Outputs

- Release readiness report.
- Final release notes.
- Deployment and rollback checklist.
