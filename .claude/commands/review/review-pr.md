# Command: Review PR

## Purpose

Run structured review of code and associated artifacts before merge.

## Required Inputs

- PR scope and linked requirements.
- Diff and test evidence.
- Known risk areas.

## Assigned Agents

- Primary: `dev-2-reviewer`.
- Secondary: `architect`, `qa`.

## Outputs

- Severity-tagged review findings.
- Merge readiness decision.
- Required follow-up actions.
