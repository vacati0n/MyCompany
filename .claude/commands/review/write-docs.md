# Command: Write Docs

## Purpose

Create or update technical documentation aligned with implemented behavior.

## Required Inputs

- Change summary.
- Audience and document type.
- Operational or usage considerations.

## Assigned Agents

- Primary: `documentation`.
- Secondary: `dev-2-reviewer` for accuracy validation.

## Outputs

- Updated technical documentation.
- Troubleshooting notes and examples.
- Documentation quality checklist.
