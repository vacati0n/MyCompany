## Implementation Summary

- Change intent: At step 1 the operator can now paste one shopee.vn product link (a product link, a short link or the link an affiliate link leads to) and press "Đọc trang". The app follows the link to the public product page, fills the product name, classification, page address and read date, offers every specification as a candidate fact row, and saves the product's own images under names it chooses (anh-doc-01 onward) for the operator to pick up to three. Every value the read filled carries a mark ("Đọc từ trang") and a "Xác nhận" button; the sheet is refused (fill-unconfirmed) until every mark is confirmed. When a read stops, or when the switch is off, the operator can paste the page text ("Dán chữ của trang sản phẩm"), which fills the same fields through the same parser with no connection, or type by hand as before. The read is behind an off switch, off by default, set in a new "Cài đặt" view. The CEO accepted the risk of a fully automatic read; the design keeps one product per click and a stop with a Vietnamese reason and the paste offer on every signal that the page refuses or cannot be read.
- Approach taken: The read runs in the web app process behind the MC-17 guard, one read at a time app-wide, with a new HTTP stack per click that is disposed when the read ends (D-001). Five new files carry it: the link and hop rule (ReadLink.cs), the sender with the accepted headers, no cookie store, no proxy, no automatic redirect, a connect-time public-address check and the read log (ReadSender.cs), the shared text parser and the page reader (ProductText.cs), the fill record, its store, the confirmation rule and the switch (FillRecord.cs), and the read itself, which composes them and saves the images (ProductRead.cs). The fact sheet is still decided by the toolchain's own check, unchanged; the read only fills the form. The test seam is an internal transport (connect target and certificate check) passed only through an internal start path that the test assembly alone can see; the shipped entry point passes none and no argument, variable, file or route sets it (D-004). The test program gains a loopback TLS fixture with a self-signed certificate made in code, PNG fixtures drawn in code, 13 new cases and a fixture host mode. Necessity and reuse: rung 1, every new file implements a design decision the Design Gate accepted (D-001 to D-015), and nothing beyond them was built. Rung 2, the routes, the request guard, the workspace, the outcome display, the fact-sheet check, the banned-term check, the plain-name rule, the socket harness, the browser launch and the test runner are reused as they are; the read is added beside them. Rung 3, the network stack, JSON, TLS, the certificate for the fixture and the image signature checks are the .NET base class library. Rung 7, the five production files exist because no existing component reads a remote page, and the design separates sender, parser, reader and record so that paste and read share one parser and the sender alone holds network types; the three test files exist because the fixture, the host mode and the cases have no MC-17 counterpart. No package, script, font or framework dependency was added.
- Design reference: technical-design.md decisions D-001 to D-015 and delivery steps P-001 to P-009 (P-010, the release note, follows this phase); success criteria SC-01 to SC-32; Scope Gate decision record entry 1314; Design Gate decision record entry 1315; decision record entry 1316 (no agent reads shopee.vn).
- Out of scope: No live read was made by this agent, and no command in this phase contacted shopee.vn or any host off 127.0.0.1. Every read in this phase went to the loopback fixture (SC-33 stays with the orchestrator, who makes the single live read per decision record entry 1316). The orchestrator's Browser-pane record on the fixture host (SC-34) is the orchestrator's. The release note and compare link (P-010) follow this phase. src/MediaCompany.Pilot and its tests are byte-unchanged; MC-13 and MC-14 material and the company store database were not touched. Nothing was signed in to, bought, published or downloaded.
