# Templates Specification

## Template Library

The template library defines canonical artifact structures for design, planning,
analysis, review, release communication, and incident learning.

## Purpose

- Standardize artifact quality and completeness.
- Improve cross-team readability and review speed.
- Enforce traceability across workflows and gates.

## Naming

- Use kebab-case filenames.
- Use descriptive nouns aligned to artifact type.
- Keep one canonical file per artifact category.
- If aliases exist for compatibility, canonical mapping must be documented.

## Ownership

- Architect owns architecture and design templates.
- Tech Lead owns implementation and operational templates.
- Reviewer and QA own review and verification template quality.
- Documentation owner governs release-note and communication templates.
