# Release Context

## Release Cadence

- Frequent, incremental releases preferred over large batches.
- Each release must pass quality gates in `config/quality-gates.md`.

## Readiness Signals

- Critical-path tests passing.
- No unresolved critical review findings.
- Rollback plan validated.

## Risk Register Categories

- Functional regression risk.
- Performance degradation risk.
- Integration compatibility risk.
- Operational monitoring gaps.
