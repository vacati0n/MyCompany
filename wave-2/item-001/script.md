## Treatment constraints this script is written against

These are gate conditions, not notes. The subject's default styling is cheerful, so each is stated
as what the script **resists** rather than as something it happens not to do.

| Condition | How this script resists it |
|---|---|
| K-1 no anthropomorphism | The forager is "a forager" and "she" only in the grammatical sense the literature uses. No name, no personality, no motive attributed, no dialogue. The colony is never "a community" or "a team". |
| K-2 scientific register | *Apis mellifera* on first mention. Claims quantified where the literature supports a quantity and explicitly hedged where it does not. Named attribution in the narration itself, not only in the end card. |
| K-3 no cartoon styling | All 22 graphics are specified in a data-visualisation idiom: axes, vectors, distributions, block diagrams. No illustrated bee character exists in the specification. |
| K-4 documentary score | Score brief is documentary register only. No song, no nursery register, no sound-effect comedy, no "boing" on the waggle. |
| K-5 metadata discipline | Title, description and tags screened against the barred-term list; see `metadata-and-thumbnails.md`. |
| K-6 no play-acting | No quiz, no "can you guess", no second-person challenge, no game framing. |
| K-7 adult-signalling element | Beats 10 to 12: the mechanism's measured error, the unresolved literature dispute, and the finding that the dance barely pays for itself in some habitats. Statistics on screen, a negative result stated plainly. |
| K-8 audience monitoring | Post-publication obligation; recorded as a standing obligation naming the parameter it waits on. |
| K-9 deliberate designation | Set per item with reasoning recorded; see `item-dossier.md` §2. |

**The single hardest line to hold** is beat 1, which is the natural place for warmth. It is written
as a problem statement — an animal with information and no channel to send it on — rather than as
a story about a bee coming home.

## The commit ordering

This script was committed **after** the supply audit was recorded, which is the obligation `C-015`
makes a precondition of the commit rather than a check applied to it.

It committed with a known and recorded gap: supply for the waggle-run clips is unestablished. The
script is written so that the gap is survivable — beats 3, 9 and 10 are carried by `GFX-02`,
`GFX-03`, `GFX-15`, `GFX-16`, `GFX-17` and `GFX-18`, and the three waggle-run clips illustrate
what has already been explained. If per-clip confirmation finds nothing that shows the dance
itself, those three clips are dropped and no claim is lost.

**No substitute is admitted.** Generic hive activity is not cut in as the waggle dance. That
substitution is the specific failure mode this niche carries, and it is refused at the script
rather than caught at review.
